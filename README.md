# NATHAN Game Engine

A simple, lightweight game engine built in C++ for the [NATHAN console](https://github.com/A-World-Felt/NATHAN-console).

## What is this?

This is the software foundation for the **NATHAN console** — an open-source game console designed for blind or visually impaired players. 

The NATHAN console, inspired by Nathan Therrien (an outstanding musician and synthesizer enthusiast), features hardware with tactile buttons and audio output. Games on this platform put you in the role of a blind protagonist who navigates through sound alone — where your ears become your eyes.

This game engine provides the building blocks to create accessible games where audio is the primary interface. It was designed to be simple to understand and use, making it easier to develop games for the NATHAN platform.

## What does it provide?

- **Scenes** - Organize your game into different screens (menus, gameplay, etc.)
- **Entities** - Game objects that can represent anything in your game world
- **Events** - A way for game elements to communicate and react to each other

## Trying it out

The project includes a demo game that shows all the features in action. Just build and run it to see how everything works together.
